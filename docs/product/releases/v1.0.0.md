# Coursekind v1.0.0

26 October 2026. First versioned local-use release, formerly Study Buddy.
Canonical repository: https://github.com/fakoli/coursekind.

## Included

- Repaired course/module authoring, study cards, quizzes, configured practices, learning paths, sharing, reuse counts and personal statistics.
- Private workspaces that turn goals into editable plans and bounded lesson/card/quiz drafts, with explicit Review and Apply.
- Scoped AI revisions, durable jobs, explicit retry/cancel, conflict detection, history and restore that preserve learner records.
- Optional JEV advisory checks of selected learning material, with backend-only credentials and current-access enforcement.
- Anvil `llm.primary` as the default; explicit BYOK OpenAI/Gemini/Anthropic choices. Codex subscription support remains disabled and is not needed for release testing.
- Mobile, keyboard and zoom repairs, locked dependencies, and an operating/backup/rollback guide.

## Install and upgrade

Clone https://github.com/fakoli/coursekind.git and check out `v1.0.0`. Follow the [operating guide](../coursekind-local-v1.md). Stop services and back up storage and private configuration before upgrading; retain the same storage path and secrets. Existing course/module/user identities and storage formats remain compatible. Repository renaming does not rename stored data.

This release publishes source through GitHub; it does not deploy a hosted service. JSON/SQLite operation is qualified for one application process. Production notifications require a transport; distributed storage, public-scale operation and teaching-quality certification are outside this release. Application credits are local accounting/quota units, not external inference charges. Existing quotas remain unchanged.
